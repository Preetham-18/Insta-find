# InstaFind 🔎

AI-powered social media archive search engine designed to help users quickly find posts from large collections without manually scrolling through thousands of posts.

## 🚀 Problem

Finding an old post from a profile containing thousands of photos and videos can be difficult because users often have to scroll through the entire profile.

## 💡 Solution

InstaFind aims to provide a smarter way to search and filter posts using:

- 🔎 Keywords
- #️⃣ Hashtags
- 📅 Date
- 🎥 Media type
- 🤖 AI-powered semantic search (planned)

## 🛠️ Tech Stack

- Python
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning / NLP
